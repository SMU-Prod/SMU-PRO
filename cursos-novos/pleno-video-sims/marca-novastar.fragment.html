A NovaStar é a marca de processamento de LED mais usada no mundo — e o software dela, o NovaLCT, é o que você mais vai encontrar em telões no Brasil. Saber o procedimento do NovaLCT de cor é o que separa o técnico que "só liga o cabo" do que resolve a parede sozinho. Nesta aula você segue o procedimento oficial do manual, botão a botão — do login admin ao Save to HW — e conhece os recursos que a locação usa todo fim de semana: Smart Settings, redundância de porta e o modo demonstração para treinar em casa.

O software real: NovaLCT

O NovaLCT (LED Configuration Tool) é gratuito, roda no Windows e é o programa oficial da NovaStar para configurar sending cards (enviadoras) e receiving cards (receptoras). Ele atende toda a linha síncrona: controladores MCTRL (MCTRL660 PRO, MCTRL4K, MCTRL1600), processadores das famílias VX e, nas receptoras, as séries A4s/A5s/A7s/A8s/A9s/A10s Plus que vivem dentro dos cabinets. Baixe sempre a versão mais recente no site oficial — o link está na aba Materiais desta aula.

Detalhe que vale ouro para quem está estudando: o manual documenta o modo demonstração — User → Demonstration Login, senha admin — que abre o software completo SEM hardware conectado, inclusive trocando o tipo de aparelho simulado em View Details of Device → Change Device Type. Ou seja: você pode instalar o NovaLCT hoje, de graça, e navegar nos mesmos menus que vai operar no evento.

Os dois níveis de acesso

Com a sending card conectada, o NovaLCT abre em modo básico: dá para usar funções comuns sem login. Para as funções avançadas — configurar tela, gravar no hardware — é preciso o login avançado: User → Advanced Synchronous System User Login, senha padrão "admin" (o manual recomenda trocá-la em User → Change Password). Por que essa trava existe? Porque um clique errado em Send reconfigura uma parede inteira no meio do show. O software separa quem olha de quem grava.

O procedimento oficial — na ordem certa

  1. Advanced Login. Menu User → senha admin. Sem isso, nada de escrever no hardware.
  2. Screen Configuration → aba Sending Card. Defina a fonte (HDMI/DVI/SDI/DP) e a resolução de entrada, confira com Refresh e clique em Send para gravar na enviadora.
  3. Aba Receiving Card. Carregue os parâmetros do gabinete — chip (IC), tipo de dado, scan, tamanho do módulo — normalmente de um arquivo de configuração do fabricante do painel (Load from File) ou pelo Smart Settings (abaixo). Depois, Send to Receiving Card: escolha All Receiving Card (todas as receptoras daquela enviadora) ou Specified (por topologia ou endereço físico) e clique em Send.
  4. Aba Screen Connection. Informe colunas × linhas de receptoras e desenhe a ordem do cabeamento porta a porta. Ligue o Enable Mapping — cada cabinet mostra seu número na própria parede, para conferir posição — e rode o Detect Communication Status: cabinet vermelho quebra a cadeia e aponta exatamente onde o cabo falhou. Para telas fora do padrão, o manual orienta configurar primeiro como tela padrão e depois ajustar em Complex Screen, arrastando os cabinets.
  5. Send to HW aplica a configuração (a parede acende) e, no diálogo seguinte, Save to HW grava tudo na memória das placas — a tela sobe sozinha no próximo evento, sem PC. O manual ainda oferece salvar um backup file local: aceite, e guarde na pasta do evento.

Smart Settings: quando o painel chega "cru"

E quando não existe arquivo de configuração do cabinet? O Smart Settings (aba Receiving Card) é um assistente de 6 etapas que descobre o painel na prática: você informa chip do módulo, tipo de dado (paralelo/serial), quantidade de pixels do módulo e tipo de decodificação de linha; o software acende padrões no módulo e vai perguntando o que você vê (qual cor apareceu, quantas linhas acenderam); nas guias finais você "desenha" a posição dos pixels clicando na grade conforme o pixel pisca. No fim, salva-se o resultado como arquivo de módulo para nunca mais precisar repetir. É o recurso que resolve painel chinês sem documentação — cena comum na locação.

Recursos de show: redundância, brilho automático e monitoramento

  • Redundância (Hot Backup): o NovaLCT configura Ethernet port redundancy — porta/cabo de backup que assume se a cadeia principal falhar. Em show com público, é obrigatório pedir o loop de backup no rider.
  • Brilho: além do ajuste manual (Settings → Brightness: brilho, gamma, temperatura e espaço de cor), há o ajuste automático por regras de horário ou por sensor de luz ligado à sending card ou à multifunction card — é assim que painel outdoor abaixa sozinho ao anoitecer.
  • Monitor: a função de monitoramento acompanha temperatura, tensão e status das placas; a Multi-function Card adiciona sensores e controle de energia remoto.
  • Test Tool: padrões de teste (cores puras, grade, cinza) direto do software — o "soundcheck" do LED antes de abrir a casa.

Onde a NovaStar está no mercado

É o processamento padrão da locação no Brasil e no mundo: a maioria dos painéis de rental sai de fábrica com receiving card NovaStar dentro. A concorrência direta é a Colorlight (forte em custo-benefício, próxima aula) e, no topo do mercado de câmera/broadcast, a Brompton (aula seguinte). O fluxo que você aprendeu aqui — entrada → receiving card → conexão → enviar → salvar — é conceitualmente o mesmo nas três marcas; muda o nome dos menus. Por isso o curso ensina o NovaLCT primeiro: é o vocabulário-mãe do LED.

No palco / erros que acontecem

  • "Configurei tudo e não gravou nada." Faltou o Advanced Login — sem ele o software não escreve no hardware. Login, senha admin, refaça o Send.
  • "A parede acendeu embaralhada em blocos." Screen Connection desenhada numa ordem diferente do cabo físico. Ligue o Mapping, confira os números na parede e redesenhe.
  • "Um cabinet ficou vermelho no Detect." Cabo/conector daquele trecho. A cadeia quebra ali: teste o cabo, feche o clique do RJ45, rode o Detect de novo.
  • "Desligou tudo e no dia seguinte a parede subiu com configuração velha." Fizeram Send to HW (aplica agora) mas não Save to HW (grava permanente). São dois cliques diferentes — o manual insiste nisso, e o mercado também.
  • "Depois do Smart Settings, metade do módulo acende deslocada." Desenho de pixel errado nas guias finais. Refaça a guia 6 com calma — um clique fora da grade desloca a coluna inteira.

Pratique no simulador

O simulador reproduz o NovaLCT: faça o Advanced Login (admin), configure Sending → Receiving → Screen Connection, use Mapping e Detect Communication, respeite a capacidade das portas e finalize com Send to HW / Save to HW. É o mesmo caminho, botão a botão, do software real — e depois instale o NovaLCT de verdade em modo demonstração para fixar.

Resumo prático

NovaStar = NovaLCT (grátis; treine em casa no Demonstration Login). Ordem: Advanced Login (admin) → Sending Card (fonte/resolução) → Receiving Card (arquivo do cabinet ou Smart Settings) → Screen Connection (mapping + detect comm) → Send to HW → Save to HW (+ backup local). Cabinet vermelho no detect = cabo; parede embaralhada = conexão desenhada diferente do cabo; "não gravou" = faltou Advanced Login ou Save to HW. Redundância de porta, brilho por sensor e Test Tool fecham o pacote de show. Dominou essa sequência, você monta qualquer telão NovaStar — e entende as outras marcas de brinde.
